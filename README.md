# Productivity App

A simple web-based productivity app for managing tasks and staying organized. Built as a school project and deployed via Netlify.

🔗 [Live demo](https://ehlproductivity-app.netlify.app/)

## Features

- Login functionality with local storage
- Create, manage and organize tasks
- Clean and simple interface

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Getting Started

### Prerequisites

- Node.js
- npm
